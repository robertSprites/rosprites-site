# Rosprites

The public website is intentionally blank. Its HTML metadata controls the text
and image shown when the link is shared in Discord and other chat apps.

The Jiren preview is `assets/jiren-dance.gif`, converted from the supplied KLIPY
MP4 into a silent, continuously looping, three-second GIF. The full animation
is preserved at 18 fps and 240×532 to keep the preview file small. The preview
description preserves the supplied text exactly, including its spelling.
Discord controls whether its link-preview card animates the GIF; this site
does not run a player or render visible content. Existing embeds may retain
cached previews; sharing a new query string can request a fresh link preview.

The previous site is preserved in Git history at commit
`ee983daab81e4e993fa9e20e39a8b424b02223c8` and in the local branch
`backup/site-before-blank-2026-10-28`. A verified ZIP backup and the original
asset/tool folders are stored outside this repository in the neighboring
`site-backups` folder.

The private Roblox analytics collector remains separate from this website.
